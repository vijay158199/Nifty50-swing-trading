Replays the strategy week-by-week over a historical date range
15-minute candles are only available from Yahoo Finance for the trailing ~60 days; a range going further back automatically falls back to 1-hour candles for the WHOLE run (flagged "Reduced" in the results) rather than mixing resolutions mid-run. 1-hour candles alone cover roughly the last 2 years. Previous-week high/low liquidity detection is unaffected either way, since it's built from daily bars. Running against all 50 stocks fetches data for each one in turn and can take several minutes - progress updates below show which stock/week it's currently on.
